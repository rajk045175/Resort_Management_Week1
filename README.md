Grand Azure Luxury Resort & Spa
A Premium Luxury Resort Booking & Management Website

Grand Azure Luxury Resort & Spa is a responsive web-based resort booking platform designed to provide guests with a premium online reservation experience. The application allows users to explore luxury accommodations, discover curated packages, browse dining options, manage reservations, and access personalized guest services.

The project features an elegant user interface with a modern luxury-inspired design, combining functionality and visual presentation.

Key Features

 🏨 1. Resort Homepage
- Elegant landing page with luxury resort branding.
- Featured resort experiences and services.
- Responsive navigation and booking options.
- Attractive banners and destination highlights.

🛏️ 2. Room & Suite Management
- Explore 10 unique architectural accommodations.
- View room descriptions, images, amenities, and pricing.
- Filter available accommodation options.
- Access detailed room information.

🎁 3. Curated Packages
- Explore exclusive resort packages.
- Filter packages based on stay duration.
- Discover customized holiday experiences.

🍽️ 4. Dining & Menu
- Browse resort dining experiences.
- Explore food menus and available options.
- Add dining selections to the cart.

👤 5. Guest Authentication
- Guest sign-in and registration interface.
- User profile management.
- Personalized guest dashboard.

📅 6. Reservation & Booking
- Select rooms and stay dates.
- Customize reservations.
- Review booking details before checkout.
- View booking confirmation and reservation voucher.

💳 7. Payment Interface
- Multiple payment method interfaces:
  - Credit/Debit Cards
  - UPI / QR
  - Net Banking
  - Wallets / EMI
- Booking payment summary.
- Payment authorization interface.

📊 8. Admin Dashboard
- Dedicated administrator console.
- Room inventory management interface.
- Guest reservation management.
- Financial overview and dashboard charts.

 🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository**

```bash
git clone https://github.com/your-username/Grand-Azure-Resort.git
```

2. Navigate to the project directory**

```bash
cd Grand-Azure-Resort
```

3. Open the project**

Open `index.html` in your web browser.

Alternatively, use the Live Server extension in Visual Studio Code for a better development experience.
